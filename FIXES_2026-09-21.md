# Hospital Record Management System — Fix Release

Date: 2026-09-21

## Completed

### Appointment notifications

- Notification links now include the exact appointment ID.
- Notification clicks use React Router navigation instead of a full reload.
- The Appointments page fetches, opens, and highlights the selected record.
- Missing, invalid, and failed appointment lookups show explicit states with
  recovery actions.
- Appointment, admission, and lab list query strings are validated before
  reaching Prisma.

### Staff accounts and demo cleanup

- Administrators may provide a policy-compliant initial password or let the
  server generate one.
- A one-time password is still returned securely to the administrator if the
  welcome email cannot be delivered, avoiding an inaccessible new account.
- Password reset and password change invalidate older unused reset tokens.
- Staff password resets are audit-logged.
- A non-demo administrator can deactivate every demo account in one action.
- Demo cleanup deactivates accounts and randomizes the shared demo password;
  it does not delete users or clinical/audit records.

### Production reliability and security

- CORS now supports an explicit comma-separated `APP_ORIGINS` allowlist and
  rejects untrusted origins.
- Production cookies default to `secure` and configurable `sameSite`; a stale
  localhost cookie domain is ignored in production.
- Express trusts the first production proxy and binds to `0.0.0.0` for Render
  and other PaaS deployments.
- Vercel SPA rewrites preserve direct route and notification-link access.
- Failed token refreshes now reject queued API calls rather than leaving them
  pending indefinitely.
- Authentication email failures no longer expose account existence or turn a
  successfully-created account/password mutation into an unrecoverable 500.
- Nodemailer was upgraded to a non-vulnerable production version.

### Engineering safeguards

- Added backend and frontend ESLint configuration.
- Added lockfiles for reproducible installs.
- Added GitHub Actions for dependency install, Prisma generation, lint, tests,
  production builds, and production dependency audits.
- Added weekly Dependabot updates for both npm packages and GitHub Actions.
